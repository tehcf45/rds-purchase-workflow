## 买RDS数据库前，先定三件事

购买页上选项很多，但真正需要你做决定的只有三样：引擎、系列、计费方式。地域跟着应用服务器走，存储和可用区用默认值基本不会出错。三件事定下来，剩下的就是填空。

### 引擎怎么选

阿里云RDS提供 MySQL、SQL Server、PostgreSQL、MariaDB 四个引擎。没有特殊理由就选MySQL：中文资料最多，主流建站程序和业务框架默认支持，版本直接上 8.0。老系统原来跑在SQL Server上，选同名引擎迁移成本最低；对复杂查询、地理信息这类能力有要求，看PostgreSQL。

有一点提前说清：AWS RDS的引擎清单里还有Oracle和Db2，阿里云RDS没有这两样，Oracle迁移的需求在阿里云走的是另一条产品线PolarDB。新建业务大概率碰不到这个问题。

## 实例买完连不上？先做这四件事

付款成功不等于能用。新手第一次连接报错，问题大概率出在白名单。按顺序做完下面四步，基本能一次连上。

1. **配置白名单**：进入实例详情，在“数据安全性”里找到白名单设置，把应用服务器的内网IP加进去。默认白名单里只有127.0.0.1这个占位地址，等于对所有连接关门。
2. **建数据库和业务账号**：管理员账号是购买时设置的，正式业务建议另建一个权限受限的账号给应用使用，出了问题也方便排查。
3. **连接数据库**：应用走VPC内网地址连接，延迟低且不经过公网；临时查数据、改表结构，用控制台自带的DMS网页版工具就行，不用装客户端。
4. **检查备份策略**：自动备份默认开启，保留天数在“备份恢复”页可调。数据重要的话，确认备份窗口和保留期符合预期。

## 几个高频问题

**RDS和自己在云服务器上装数据库，差在哪？**

差的是运维。自建省下的是实例差价，但备份、监控、主备切换、安全补丁全要自己负责，数据库半夜出故障也得自己爬起来处理。RDS把这些活托管了，代价是同配置下贵一些。正式业务里，这点差价通常花得值。

**单独购买RDS数据库需要备案吗？**

不需要。备案针对的是接入中国大陆节点的网站域名，数据库实例本身不在备案范围内。你的网站要是部署在大陆需要备案，那是网站侧的事，和买不买RDS无关。

**地域选错了怎么办？**

改不了，只能释放或退掉重买，数据靠备份导出再导入。这就是下单前务必确认应用服务器所在地域的原因。

**预算很紧，怎么起步最省？**

基础系列加最小规格，按量付费跑着，用完就释放；项目转正式再升级到高可用系列、改成包年包月。规格和存储随时能升，起步阶段不用纠结。
